# Site Runner 像素图标

源图为一个 32 × 32 的整数像素网格。浏览器、地球、箭头使用同一套坐标，整体向右、向下各偏移一格。背景阶梯圆角也按整格绘制，没有抗锯齿、渐变或透明边缘杂点。

运行 `pnpm icons:generate` 可重建全部文件，无需额外依赖：

- `icon.svg`：应用内标题栏图标，整数坐标，`crispEdges`。
- `icon.png`：1024 × 1024，源像素整数倍放大。
- `icon-32.png`：原始网格；其余 PNG 为系统尺寸，使用最近邻采样。
- `icon.icns`：macOS 多尺寸图标。
- `icon.ico`：Windows 多尺寸图标。
- `pixel-grid.json`：调色板、偏移量和完整像素矩阵。

16 像素版本通过最近邻缩小，属于缩略图；32、64、128、256、512、1024 像素版本保留同一网格的整数倍关系。
