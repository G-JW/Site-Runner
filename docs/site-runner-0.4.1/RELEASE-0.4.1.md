# Site Runner 0.4.1

0.4.1 衔接线上 0.3.9。此前 2.0 的名称仅用于本地内部试作，未发布为正式版本。

## 更新内容

- 主导航精简为任务、运行记录、设置；模板、账号环境、通知和备份从设置进入。任务摘要、筛选和批量操作减少常驻信息。
- 任务编辑器使用居中表单和横向步骤，继续支持现有 TypeScript 脚本、可视化流程、录制、试运行与计划。
- 设置 → 执行 → 并行任务数支持 1–10 个，默认 3 个；设为 1 恢复串行。手动与定时任务共用全局上限，共用登录环境也可使用独立页面并行。
- 设置 → 外观 → 配色主题 → 跟随系统支持实时深浅色切换，保留手动主题与本地偏好。
- 版本标识从实际应用版本读取，界面、包元数据、标签和更新清单统一使用 0.4.1。

## 从 0.3.9 升级

完全退出并重新打开 0.3.9，进入 **设置 → 软件更新 → 检查更新 → 更新并重启**，目标应为 **0.4.1**。不需要先安装中间版本或重新建立任务。

应用名称、数据目录与更新验证公钥沿用。更新包不包含用户数据，已有任务、脚本、分组、登录目录、通知和历史继续使用。运行中的任务、录制及登录浏览器需要先完成或关闭。

发布前已用 GitHub 官方 0.3.9 Apple Silicon 安装包的客户端副本，实际点击更新按钮安装原密钥签名的本地 0.4.1 更新包，完成下载校验、解包清理、替换、GUI 重启；任务、脚本、语言、主题和登录目录保留。测试使用临时应用副本和合成数据，未操作正式账号。

本地验证见 [upgrade-local-verification.json](upgrade-local-verification.json)。线上下载与安装的验证结果会补充在 [GitHub Release](https://github.com/G-JW/Site-Runner/releases/tag/v0.4.1) 说明中。

## 验证范围

- 类型检查、Lint、生产构建，以及 31 个测试文件的 105 项测试通过。
- 最终 macOS Apple Silicon 应用通过真实 Electron 的导航、最小窗口中英文、录制保护、全局日志、并行执行、卡死 Worker 隔离、主题实时切换和重启保存回归。
- 保留旧版更新器兼容布局与原 Ed25519 公钥；三平台发布包及签名更新清单由 GitHub Actions 统一生成，全部构建成功后才公开 Release。
- Windows 安装与自动更新流程仍需 Windows 实机验证，构建成功不等同于实机验证。

详细记录见 [verification.json](verification.json)、[parallel-verification.json](parallel-verification.json) 和 [system-theme-verification.json](system-theme-verification.json)。
