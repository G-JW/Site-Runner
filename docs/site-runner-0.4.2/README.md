# 0.4.2：简洁界面、每日执行与 Mac 菜单栏

本地 Apple Silicon 应用：`release/0.4.2/mac-arm64/Site Runner.app`。未发布到 GitHub，也未替换 `/Applications` 中的旧版。先用 ⌘Q 退出旧版，再打开新版；继续沿用原数据目录和登录环境。

## 界面

结合方案 A 与现有任务列表，使用浅蓝强调色、冷白工作区与更清晰的间距，保留深色/跟随系统、密度和语言设置。

删除顶部“工作空间”面包屑、快捷搜索按钮与快捷键提示、重复的顶部输出按钮、左下角“数据保存在本机”和任务页宣传语/计划页脚。⌘K / Ctrl+K 搜索、⌘J / Ctrl+J 输出以及左下角运行输出入口仍保留。

## 每日执行

- 任务页右上角点击“每天 09:00”设置开关和时间；设置 → 执行中也可调整。
- 默认开启，每天 09:00，使用设备本地时区。
- 定时触发时，运行所有已启用且未处于执行/排队状态的任务，包含原来设为“仅手动”的任务；停用的任务不执行。
- 复用原并行执行上限、登录环境、运行记录和定时通知选项；不调用外部命令。
- 开启统一计划后，单站和分组计划暂停触发，其设置保留；关闭统一计划后恢复。
- 当天的自动批次只触发一次，重启或修改时间不会重复触发；手动运行不受限制。已经触发过后，当天修改时间也不会再次自动执行。
- 应用需保持运行。设备睡眠、应用完全退出期间不执行，不补跑、不唤醒电脑。
- 导入并应用备份时，全局每日计划与其他自动计划一样保持暂停，避免意外运行。
- 原来的 CLI（`--run-all` 等）仍保留，常驻使用无需配置外部调度。

## Mac 菜单栏

关闭窗口（红色关闭按钮或 ⌘W）后保留后台进程，隐藏 Dock 图标，调度继续工作。菜单栏提供“打开 Site Runner”“运行全部已启用任务”、当前每日时间和“退出 Site Runner”。打开窗口时恢复 Dock；重新启动已驻留的软件也会恢复窗口。

使用临时的单色模板图标和 Retina 资源（`assets/branding/trayTemplate.png`、`trayTemplate@2x.png`），随菜单栏明暗自动着色，后续可独立设计替换。

完全退出使用菜单栏中的“退出 Site Runner”或 ⌘Q；关闭窗口不再表示退出。没有添加开机自启动或修改系统任务。
