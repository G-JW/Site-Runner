## 新功能

- 新增每日统一定时执行及“打开应用时补跑今日任务”开关，默认开启补跑。过了今日执行时间后，启动应用或从菜单栏恢复窗口时，只补跑今天尚未执行的启用任务，不追溯以前日期。
- 每日自动批次去重；关闭统一计划后恢复原有单站和分组计划。
- Mac 关闭窗口后驻留菜单栏并隐藏 Dock 图标，可从菜单栏恢复窗口、运行任务或退出。暂用单色模板图标。
- 结合浅色方案 A 精简界面，移除工作空间、重复搜索/输出入口、本地存储页脚和任务页说明文字。

## 体积优化

- 有界面和无界面执行共用完整 Chromium，停止携带第二套 headless shell。
- Monaco、React 等已编译进前端的依赖不再作为运行时模块重复打包；脚本编辑功能保留。
- 本地 macOS arm64 安装目录从 1,095.8 MiB 减至 760.1 MiB，减少约 31%。各平台发布包大小以实际下载为准。

## 使用

任务页右上角“每天 HH:mm”或“设置 → 执行”可设置每日时间和补跑开关。睡眠及完全退出期间不执行；补跑仅在重新打开时检查。原 CLI 继续保留。

已有任务、脚本、登录状态和历史继续使用原数据目录。软件更新可从旧版设置中检查；应用完全退出使用 ⌘Q 或菜单栏“退出”。
