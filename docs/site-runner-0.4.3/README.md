# 0.4.3：体积精简与打开应用时补跑

## 实测构成（本地 macOS arm64，du 分配空间）

| 部分 | 0.4.2 | 0.4.3 | 处理 |
|---|---:|---:|---|
| Electron 和辅助框架 | 317 MiB | 317 MiB | 保留，提供桌面界面 |
| 完整 Chromium | 382 MiB | 382 MiB | 保留，登录、录制和任务共用 |
| 独立 headless shell | 211 MiB | 0 | 移除；生产启动固定 channel: chromium |
| Playwright FFmpeg | 3.1 MiB | 3.1 MiB | 保留，避免破坏媒体功能 |
| 应用代码和运行依赖 | 182 MiB | 58 MiB | 前端依赖改为开发依赖，保留编译后编辑器与 UI |
| 合计 | 1,095.8 MiB | 760.1 MiB | 减少约 335.7 MiB / 30.6% |

Monaco 原模块约 111 MiB，占重复前端依赖的大头。它的运行代码仍在 dist/renderer 中，不是删除编辑器。Chromium 是自动化浏览器，Electron 内的 Chromium 是桌面 UI 引擎，目前不是可直接相互替换的资源。改成复用系统浏览器或 Electron 自身作为自动化浏览器需要另一轮兼容性设计。

可另行清理的历史内容包括：项目 release/ 中旧版本应用与 zip、应用安装器生成的 .backup-* 旧版、已完成更新的下载缓存。这些不属于当前版本的必需文件。本次不批量删除旧版本和用户历史数据。用户数据目录中的 profiles 含登录状态，site-runner.sqlite3 含任务/历史，不能当成安装包冗余删除。

## 补跑行为

默认开启“打开应用时补跑今日任务”。检查条件：统一每日计划开启、补跑开关开启、本地时间达到今日执行时间、当天还有尚未执行的启用任务、当天自动批次尚未触发。

触发检查的时机为应用启动和恢复窗口，不在修改设置时立即运行。只补今日，不补以前日期。当天已有运行记录的任务（包括失败记录）不会因为补跑再次运行。设置和每日去重标记持久化到 SQLite；重启/重复恢复窗口不会重复执行。关闭开关时仅按原定时间运行。

单站或分组计划在统一计划启用时保留配置、暂停触发；关闭统一计划后恢复。补跑与常规定时共用既有并发限制、运行记录和通知配置。

## 发布与验证

该版包含尚未公开发布的 0.4.2 界面、每日计划和 Mac 菜单栏功能。

本地执行通过：ESLint、前后端类型检查、115 项回归测试和生产构建。精简后的实际应用包通过 --automation-smoke-test（本地示例任务，2 成功 / 1 预期失败），证明不依赖被移除的 headless shell 和前端模块。

Mac 菜单栏原生点击与 Dock 行为仍缺少人工交互实测；已有 mock 测试，上一轮原生桌面控制连接超时。Windows 与 Intel Mac 的构建状态见该版本 GitHub Actions，不等同于实机验证。
